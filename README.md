# 仓库计费配置 · 独立评审原型

直接访问：https://kayleylee1128-gif.github.io/warehouse-billing-meeting-prototype/

## 范围

自建仓作业成本配置。仅含虚构演示仓库、人员与价格，不含报价卡原文、会议原文及真实经营数据。原始站点未覆盖。

- 单个生效日期；一个节点一套价格规则。
- 收货：箱数（包裹数）或入库单。选箱数直接填写箱数范围和单价；选入库单直接填写每单价格。
- 质检：实际抽检数量，直接填写品类、数量范围和单价。
- 其他作业节点仅开放匹配其数据来源的单位与属性。
- 生效版与审批中版本并行展示。钉钉审批为模拟演示。
- 默认开启交互标注，支持分类与双向定位。
- 不涉及全链路库存。真实后台未接入；正式应用计算范围仍为拣货。

## 运行

安装Node.js后 npm install，再 npm run build。构建产物在docs。直接静态托管docs即可。

原型数据保存在当前浏览器localStorage；浏览器之间不共享。
