# 仓库计费配置 · 独立评审原型

直接访问：https://kayleylee1128-gif.github.io/warehouse-billing-meeting-prototype/

## 范围

仓库成本与收入独立计费配置。仅含虚构演示仓库、人员与价格，不含报价卡原文、会议原文及真实经营数据。原始站点未覆盖。

- 单个生效日期；一个节点一套价格规则。
- 收货：箱数（包裹数）或入库单。选箱数直接填写箱数范围和单价；选入库单直接填写每单价格。
- 质检：质检在同一表格前面维护适用条件，后面并列维护每款、每件单价，两项费用相加。
- 其他作业节点仅开放匹配其数据来源的单位与属性。
- 生效版与审批中版本并行展示。钉钉审批为模拟演示。
- 默认开启交互标注，支持分类与双向定位。
- 不涉及全链路库存。真实后台未接入；正式应用计算范围仍为拣货。

## 运行

安装Node.js后 npm install，再 npm run build。构建产物在docs。直接静态托管docs即可。

原型数据保存在当前浏览器localStorage；浏览器之间不共享。

费用统计入口：https://kayleylee1128-gif.github.io/warehouse-billing-meeting-prototype/fees.html?v=8

费用统计为拣货任务模拟月账，使用独立归档示例价格展示，未连接当前浏览器中的配置草稿或真实WMS。支持仓库、节点和员工下钻、原始记录查看及CSV导出。

上架：同一条件行维护每库位、每件单价，两项费用相加。贴标固定按件，不展示计算方式。退件处理仅按退件单或件计量，按单件实重定价。

打包：同一价格行支持多条件且组合；按行顺序匹配首个命中价格。

质检仅按品类、单件实重、单件体积组合匹配价格；款数与抽检件数为计费数量。拣货固定库位费加件数费，定价依据仅单件实重、单件体积、单件最长边。费用月账、汇总工作量及明细导出同时包含库位与件数。

打包固定款数费加件数费，只有按量计费；盘点固定库位费加件数费。库内作业新增组拆换码、按件收费。出库仅按袋内包裹数匹配价格。配置列表不展示费用计算时机。仓库详情支持作业完成日期、员工、节点共同筛选并导出当前结果。

## 成本与收入

配置入口在同一仓库下切换成本计费、收入计费，两类账本分别维护报价、审批版本和生效时间。收入按入库、出库、退件、仓储服务报价，并关联作业成本节点。当前收入报价范围为仓库通用报价。

统计页面展示成本费用，保留节点、员工两种汇总视图。配置端仍保留成本与收入独立配置。

加入双账本前的独立原型：https://kayleylee1128-gif.github.io/warehouse-billing-meeting-prototype/cost-only/index.html

恢复标签：before-cost-income-20261119。恢复说明见 COST_INCOME_ROLLBACK.md。

打包条件支持订单类型（速卖通仓发、速卖通JIT、其他所有）与原有条件组合。仓库费用统计详情在按节点视图中展开人员工作量：拣货显示员工、工号、订单数、SKU款数、SKU件数、工作量和总工作量；打包另含订单类型、订单件型。工作量=订单数+款数+件数。支持订单追溯与导出，独立模拟作业数据不计入拣货费用或毛利。

打包价格行固定必填订单类型、单内件数、单内款数，重量和体积为可选组合条件；分别维护每款和每件单价。旧包裹单价不自动迁移为每款价格，新单价与缺失条件须补齐后提交。
